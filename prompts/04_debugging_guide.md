# Debugging & Common Issues

## Build environment

| Item | Value |
|---|---|
| Language | Free Pascal (ObjFPC mode, `{$mode objfpc}{$H+}`) |
| IDE | Lazarus 2.x |
| Required packages | `Printer4Lazarus`, `LCL` |
| Output | `zplview.exe` (Windows GraphicApplication) |
| Debug build | Heap trace + range/overflow/IO/stack checks + Dwarf2 |

---

## Common compile errors

### `Unknown identifier 'TINetServer'`
- Add `ssockets` to the `uses` clause.

### `Unknown identifier 'NetAddrToStr'`
- Add `Sockets` (capital S, low-level unit) to `uses`.

### `Interface not implemented`
- If adding a new method to `IZplRenderer`, implement it in **all** classes that implement the interface (`TLabelaryRenderer` + any custom renderers).

### `Incompatible types: expected BOOLEAN got LONGINT`
- `INI.ReadBool` returns `Boolean`; `INI.ReadInteger` returns `Integer`. Use the correct call.

## Runtime issues

### No image displayed after receiving ZPL
1. Check that `zpldatalen > 0` — the buffer may be empty if the TCP connection closed before data was flushed.
2. Check Labelary API response: errors are shown via `ShowMessage` — watch for network/firewall blocks on port 80.
3. Verify DPI/size settings match the ZPL label dimensions.

### Socket binding fails silently
- Port 9100 may already be in use. Change `tcpport` in settings.
- `ReuseAddress = True` helps with `TIME_WAIT` on restart.

### Print output is blank (GDI mode)
- `Image1.Picture.Graphic` must not be nil — render must succeed first.
- The `StretchDraw` rect is calculated as `image_pixels * printer_DPI / label_DPI`.
  If `settings.resolution` doesn't match the actual label DPI, scaling will be wrong.

### Raw print produces no output
- Verify the printer supports ZPL passthrough (raw mode).
- `Printer4Lazarus` raw mode requires the printer driver to accept raw data — thermal Zebra drivers do, generic GDI drivers do not.

## Extending the TCP buffer

The buffer is fixed at 1 MB (`GetMem(zpldata, 1000000)`).
To increase it, change all three occurrences consistently:

```pascal
// zplview_main.pas — FormCreate
GetMem(zpldata, 4000000);
FillChar(zpldata^, 4000000, 0);

// FormClose
FreeMem(zpldata, 4000000);

// ReadJetData — the read loop limit
len := DataStream.Read((zpldata + zpldatalen)^, 4000000 - zpldatalen);
```

## Localization

- Base language: **German** (`po/zplview.po`)
- Template: `po/zplview.pot` (auto-generated by Lazarus)
- To add a language: copy `.pot` to `zplview.XX.po`, translate `msgstr` entries, compile with `msgfmt`
- String extraction is automatic when building — controlled by `<i18n><EnableI18N Value="True"/>` in `zplview.lpi`
